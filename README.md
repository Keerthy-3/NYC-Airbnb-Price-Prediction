# Minor Project 2 – Predict New York City Airbnb Prices

## Project Overview

This project uses Exploratory Data Analysis (EDA) and Linear Regression to analyze Airbnb listings in New York City and predict listing prices based on features such as location, room type, minimum nights, reviews, and availability.

## Dataset

**New York City Airbnb Open Data (AB_NYC_2019.csv)**

Source: Kaggle Dataset Link: [https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

The dataset contains approximately 48,895 Airbnb listings and 16 columns describing listing details, locations, prices, reviews, and availability.

## Analysis Performed

- Dataset understanding
- Data types and feature classification
- Missing-value analysis and handling
- Data cleaning and removal of unnecessary columns
- Outlier detection and handling
- Categorical feature encoding
- Feature and target selection
- Training and testing data split
- Linear Regression model training
- Price prediction
- Model evaluation using R², MAE, MSE, and RMSE
- Actual vs. predicted price scatter plot
- Residual plot analysis
- Comparison of prediction performance for cheaper and more expensive listings
